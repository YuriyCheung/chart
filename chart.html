Library Self-Checkout Process Flow

Select books → Self-checkout → Exit gate

flowchart TD
    A([START]) --> B["1. Reader selects one or more books"]
    B --> C["2. Walk to self-checkout area"]
    C --> D{"3. Self-checkout
machine available?"}

    D -- No --> D1["Queue for machine"]
    D1 --> D2["Machine becomes available"]
    D2 --> E

    D -- Yes --> E["4. Select language / start transaction"]

    E --> F["5. Scan library card, HKID,
or account identifier"]
    F --> G{"6. Account recognised and
borrowing permitted?"}

    G -- No --> G1["Seek staff assistance"]
    G1 --> G2["Staff verifies account /
explains issue"]
    G2 --> G3{"Issue resolved
immediately?"}
    G3 -- No --> G4([Transaction ends])
    G3 -- Yes --> F

    G -- Yes --> H["7. Place books on RFID reader"]
    H --> I{"8. System reads every
item correctly?"}

    I -- No --> I1["Reposition books and rescan"]
    I1 --> I2{"Still unreadable?"}
    I2 -- Yes --> I3["Staff assistance or
manual handling"]
    I3 --> J
    I2 -- No --> J

    I -- Yes --> J["9. System displays titles and due dates"]
    J --> K["10. Reader confirms borrowing"]
    K --> L["11. System updates account and
deactivates item security"]
    L --> M{"12. Receipt required?"}

    M -- Yes --> M1["Print or send electronic receipt"]
    M1 --> N
    M -- No --> N["13. Pass through exit gate"]

    N --> O{"14. Gate alarm sounds?"}
    O -- Yes --> O1["Return to staff desk for checking"]
    O -- No --> P([EXIT])

    class A,P startEnd
    class B,C,E,F,H,J,K,L,N step
    class D,G,G3,I,I2,M,O decision
    class D1,D2,G1,G2,G4,I1,I3,M1,O1 offpath
